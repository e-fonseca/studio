Como o sistema é atualizado

Toda entrega é um pacote completo, um arquivo .zip único. Quem atualiza salva esse arquivo em C:\instalacao e roda, no PowerShell como administrador:

powershell -ExecutionPolicy Bypass -File C:\instalacao\atualizar.ps1

O script faz backup do banco, troca os arquivos do programa, aplica as mudanças de banco, confere se elas entraram, refaz as permissões dos perfis e roda uma importação no fim. Ele também limpa a pasta C:\instalacao: guarda os três últimos pacotes, logs de 90 dias e as duas versões anteriores do sistema. Não existe "pacote de correção" avulso: se o número da versão no topo da tela não mudou, a atualização não entrou.

Como o sistema é higienizado

Todo dia às 03:40 o sistema limpa sozinho o que acumulou: a cópia do banco do SET que a importação já leu, as fotos de dados além das dez últimas sincronizações, sessões vencidas, registros de acesso e de envio com mais de 90 dias e arquivo de anexo sem dono. Para ver o que há para limpar, sem limpar nada:

powershell -ExecutionPolicy Bypass -File C:\cabana-sistema\scripts\higienizar.ps1 -Conferir

O mesmo comando sem o -Conferir limpa na hora. O que uma pessoa digitou — ficha de fornecedor, pagamento previsto, inventário, extrato conferido, auditoria — nunca entra nessa limpeza, e nada nela encosta no SET.

{% comment %}Os dois comandos juntos, a pedido dele em 19/10/2026: quem abre o PowerShell no servidor costuma fazer as duas coisas na mesma visita, e procurar o outro comando em outro lugar da página é o que ele não quer fazer.{% endcomment %}

Os comandos do servidor, na ordem em que se usam

Atualizar o sistema
powershell -ExecutionPolicy Bypass -File C:\instalacao\atualizar.ps1
Conferir a limpeza, sem limpar
powershell -ExecutionPolicy Bypass -File C:\cabana-sistema\scripts\higienizar.ps1 -Conferir
Higienizar agora
powershell -ExecutionPolicy Bypass -File C:\cabana-sistema\scripts\higienizar.ps1

Nenhum dos dois é obrigatório no dia a dia: a higienização roda sozinha às 03:40 e a atualização só quando chega pacote novo. Estão aqui para quando alguém quiser fazer na hora.
